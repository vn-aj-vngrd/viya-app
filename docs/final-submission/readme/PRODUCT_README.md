# Viya Product README

## Product Summary

Viya is a mobile AI travel workspace. It helps a traveler move from a rough trip idea to a prepared trip workspace with itinerary, budget, Vault documents, bookings, readiness, places, notes, risks, companions, moments, and recap.

The product promise is simple:

> Plan in Viya. Book anywhere. Ask Viya anytime. Let Viya organize everything.

## Problem

Travel planning is fragmented. A single trip can live across chat threads, email confirmations, booking apps, maps, screenshots, receipts, notes, calendar events, and spreadsheets. The traveler has to connect the plan, the proof, and the final preparation state manually.

Most AI travel tools stop at itinerary generation. Viya treats itinerary generation as only one part of a larger workspace.

## Solution

Viya gives each trip a structured workspace:

- Home dashboard for active trips and trip ideas.
- Guided trip creation for destination, dates, budget, pace, and traveler context.
- Trip Overview for readiness, budget, and next action.
- Ask Viya for trip-scoped planning and workspace operations.
- Itinerary for days, stops, pace, and route context.
- Budget for planned spend, logged spend, remaining room, and receipts.
- Vault for confirmations, passes, receipts, and travel documents.
- Readiness for concrete prep tasks and final travel confidence.
- Supporting modules for bookings, places, notes, risks, companions, travel mode, moments, and recap.

## Target Users

- Travelers who want confidence before departure.
- First-time travelers who need help with requirements and documents.
- Busy professionals planning work or conference trips.
- Budget-conscious travelers who want spend visibility.
- Groups that need one shared source of truth.
- Travelers who want a post-trip story or reusable template.

## What The Demo Proves

The Singapore Tech Week demo proves that Viya can turn a trip profile and fixture documents into a ready workspace:

- Four-day Singapore trip profile.
- Itinerary with conference anchors and light pacing.
- Budget status against a PHP 90,000 planning ceiling.
- Vault fixture files for flight, hotel, event pass, expense, and readiness note.
- Readiness score reaching 100%.
- Ask Viya as the AI entry point for module updates and audits.

The Singapore content is fictional demo data. The product flow is designed to remain trip-agnostic.
