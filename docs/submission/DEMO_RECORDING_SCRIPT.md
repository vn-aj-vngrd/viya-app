# Viya Demo Recording Script

## Goal

Show a complete product path without relying on a live pitch. The recording should prove that Viya can move from idea to a ready travel workspace.

## Recording Path

1. Open Viya.
2. Log in.
3. Complete onboarding.
4. Land on Home and show dashboard suggestions.
5. Open Trips.
6. Create a trip using the Singapore group reward prompt.
7. Answer Viya's key questions.
8. Confirm the Singapore trip workspace is created.
9. Open AI chat and ask what is missing.
10. Generate or apply itinerary.
11. Open Budget and show the planning ceiling and tracked spend.
12. Open Vault and show the fixture files.
13. Open Readiness and run the final check.
14. End on the Overview or Readiness screen showing 100% preparedness.

## Voiceover Copy

Viya is not another inspiration board. It is an AI travel workspace. The user starts from Home, creates a trip through guided AI questions, and then Viya turns the latest trip content into itinerary, budget, Vault, and readiness. The demo ends when readiness confirms the traveler is prepared.
