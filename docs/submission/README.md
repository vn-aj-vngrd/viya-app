# Viya Submission Pack

This folder collects the written artifacts that support the Viya pitch deck.

## Primary Files

- `AI_APPLICATION_AUDIT.md`: required audit document covering instructions, solution, infrastructure, tools, APIs, and versions.
- `USER_GUIDE.md`: short judge-facing product guide.
- `DEMO_RECORDING_SCRIPT.md`: recording path for a clean no-live-pitch demo.
- `SUBMISSION_MANIFEST.md`: artifact checklist and file locations.
