# Viya User Guide

## What Viya Does

Viya helps a traveler turn a trip idea into a ready workspace. Instead of leaving plans in chat, Viya creates connected modules for itinerary, budget, Vault documents, and readiness.

## How To Use It

1. Open Viya and complete onboarding.
2. Use Home to see dashboard context and trip suggestions.
3. Create a trip.
4. Answer only the key trip questions Viya asks.
5. Let Viya generate the itinerary, budget, Vault setup, and readiness checklist.
6. Upload or attach travel proof in Vault.
7. Review AI-staged changes before applying them.
8. Finish when readiness reaches 100%.

## Demo Prompt

```txt
Viya, plan my Singapore group business-conference reward trip. I'm going for Tech Week, want it polished but not exhausting, and I need the workspace to handle flights, hotel, event pass, budget, itinerary, readiness, and a little victory lap. Ask only what you need, then build the trip.
```

## What To Look For

- AI chat asks only useful questions.
- The workspace is structured, not just a conversation.
- Vault documents become useful trip context.
- Budget and itinerary are visible modules.
- Readiness is the final completion signal.
